# **App Name**: Directory Detective

## Core Features:

- Directory Crawling and File Tree Generation: Recursively scan specified directories, building a visual file tree to display the directory structure.
- File Difference Analysis: Detect and highlight differences between files, showing a side-by-side comparison of content and metadata.
- Duplicate File Detection: Identify duplicate files based on name and hash values, enabling users to manage redundant copies.
- File Salvage: Use the tool to watch the specified system's folders to detect file changes, or duplicate specified folders.
- Smart Extraction: Analyze dependencies between files; suggest required files when you point the tool at an artifact you would like to run in isolation. As a tool, this may incorporate information regarding wildcard usage for file analysis or rules for file ignoring, options to rename/delete.
- Mass Find and Replace: Conduct find and replace operations across a selection of files, with results saved for later use.
- Visio-Style Visualization: Transform file relationships into interactive, dynamic graphs, presented in flowchart diagrams, and incorporate user direction anywhere in the scanned results for ongoing directory analysis.
- Gemini CLI Communication: A dual pane window for communication with Gemini CLI as an advanced extension of my vision as mechanic rech advisor helping me modify the tool as we use it and make features to the tool as he figures out what it took to produce desired out put.

## Style Guidelines:

- Primary color: Forest Green (#3F704F), symbolizing growth and organization, but without leaning too heavily into a "money" metaphor.
- Background color: Light Beige (#F2EFE9), providing a neutral and calming backdrop.
- Accent color: Mustard Yellow (#D4A54F), drawing the user's attention to details.
- Headline font: 'Space Grotesk', sans-serif, providing a computerized, techy look. Body font: 'Inter', a sans-serif, for longer form text.
- Consistent iconography representing various file types, actions (delete, merge), and analysis types, ensuring usability.
- A modular design with expandable panels for file details, analysis results, and operation logs; panels may be introduced anywhere in the scanned results based on user choices.
- Subtle transitions during file crawling and analysis to signify ongoing processes; focus attention through the visualization when errors arise.
